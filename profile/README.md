**DownloadX.id** adalah direktori download software gratis, *open-source*, dan *freeware* legal untuk **Windows, macOS, dan Linux** di Indonesia. Seluruh tautan unduhan diarahkan langsung ke server atau repositori resmi pengembang tanpa *repack*, tanpa *installer wrapper*, dan dilengkapi verifikasi checksum **SHA-256**.

## Prinsip Kurasi

- **Direct Vendor Links Only:** Domain pengunduhan dikunci di server (`allowed_domains`) agar hanya mengarah ke situs atau repositori resmi vendor.
- **Verifikasi Kriptografi SHA-256:** Setiap aset biner dicatat nilai hash SHA-256 resminya dan dapat diuji secara lokal di browser lewat [downloadx.id/cek-hash/](https://downloadx.id/cek-hash/).
- **Pemantauan Keamanan & Rilis Otomatis:** Rilis baru dipantau berkala dan diaudit terhadap laporan VirusTotal sebelum dipublikasikan.
- **Evaluasi Editorial Berimbang:** Setiap halaman aplikasi memuat kelebihan dan keterbatasan nyata tanpa ulasan promosi satu arah.

## Repositori Publik

- [`sha256-verifier`](https://github.com/downloadxid/sha256-verifier) — Skrip CLI ringan untuk Windows PowerShell & macOS/Linux guna menghitung checksum SHA-256 installer secara lokal dan mencocokkannya dengan arsip hash resmi.
- [`awesome-software-legal-id`](https://github.com/downloadxid/awesome-software-legal-id) — Daftar kurasi terbuka software gratis, *open-source*, dan pengganti legal aplikasi berbayar untuk pengguna Indonesia.
